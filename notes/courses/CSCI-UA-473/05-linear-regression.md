## Noise in the targets

*Slides 3-4.* This section repairs an assumption that every lecture so far has leaned on.
[L3](note.html?course=CSCI-UA-473&note=03-components-of-learning) posited an unknown target
function $f$ and [L4](note.html?course=CSCI-UA-473&note=04-feasibility-of-learning) built
Hoeffding on top of it. Both treated $f$ as **deterministic**: $y = f(x)$.

In reality the mapping $x \to y$ rarely is. The deck's example is two customers with
*identical* input features who behave differently on repayment. Nothing is wrong with the
model; the uncertainty is structural, and its source is named plainly:

> This uncertainty stems from the fact that $x$ may not capture the entirety of the
> variables.

So instead of a single deterministic output, treat $y$ as a **random variable** and model
its distribution given $x$:

$$
P(y \mid x),
$$

with $P(y = 1 \mid x)$ the probability that customer $x$ does *not* default and
$P(y = 0 \mid x)$ that they do. A data point $(x,y)$ is then generated by a joint
distribution that factors:

$$
P(x, y) = P(x)\,P(y \mid x).
$$

Two readings of that factorization, and the deck names both:

| Factor | Name | What it does |
|---|---|---|
| $P(x)$ | **input distribution** | the relative importance of the input samples |
| $P(y \mid x)$ | **target distribution** | what we are really interested in finding out |

And the reconciliation with the old picture: a noisy target is a deterministic target
$\hat y = \mathbb E[y \mid x]$ **plus** added noise $\hat y - f(x)$, the residual. The
deterministic $f$ of L3 was never wrong, it was the conditional mean all along; what L5
adds is everything the conditional mean throws away.

Worth holding onto for L4's sake: this is why $E_{\text{out}}$ can be bounded below away
from zero no matter how good $\mathbb H$ is. The noise is in $P(y\mid x)$, not in the
hypothesis set, so no amount of capacity removes it.

## The credit line problem

*Slide 5.* Eight features on a customer:

$$
x = [x_1, \dots, x_8]
$$

age, gender, education, annual income, FICO score, marital status, home ownership, zip
code. The goal is to estimate **the amount of credit line to lend**, $y$.

This is deliberately the same scenario L3 used for classification, moved one step over: L3
asked approve/reject with $\mathcal Y = \{+1,-1\}$, L5 asks *how much* with
$\mathcal Y = \mathbb R$. The deck flags what the feature list forces you to deal with -
some variables are continuous, some binary, and some **categorical**, taking only finitely
many values.

## Representing categorical variables

*Slide 6.* One-hot coding, with education as the worked case:

$$
x \in \{\text{Middle School},\ \text{High School},\ \text{Undergraduate},\ \text{Graduate},\ \text{Doctoral},\ \text{Post-doctoral}\}
$$

becomes six binary columns, each level getting the identity row with a single 1:

| Level | Encoding |
|---|---|
| Middle School | `1 0 0 0 0 0` |
| High School | `0 1 0 0 0 0` |
| Undergraduate | `0 0 1 0 0 0` |
| Graduate | `0 0 0 1 0 0` |
| Doctoral | `0 0 0 0 1 0` |
| Post-doctoral | `0 0 0 0 0 1` |

L3 already gave the *why* - one-hot avoids imposing a false ordering and false spacing on
levels that have neither. Note that education is a case where an ordering arguably does
exist; what does not exist is a defensible claim that Doctoral minus Graduate equals
Graduate minus Undergraduate, which is what a single numeric column would assert.

## The learning system

*Slide 7.* The L3 components diagram, instantiated:

- $D = \{(x^1,y^1), \dots, (x^N,y^N)\}$, historical customer data.
- An unknown target $f : \mathcal X \to \mathcal Y$ with $y^i = f(x^i)$ for all $i$.
- Search for $g \approx f$, and the first order of business is choosing $\mathbb H$.
- For linear regression, $\mathbb H$ is **the set of all linear parametric functions**.

The slide's phrasing of what choosing $\mathbb H$ commits you to is worth keeping: it
"indicates our belief that the space $\mathbb H$ contains the function $g$ that will
approximate $f$ **probabilistically**." That adverb is doing the work the noise section
just introduced.

## The model

*Slides 8-9.* For $x = [x_1, \dots, x_d]$:

$$
h(x) = w_0 + \sum_{i=1}^{d} w_i x_i,
$$

with $w = [w_0, w_1, \dots, w_d]$ the learnable parameters. The assumption is that $f$ is
**well approximated by a linear function**.

Then the definitional point, which the deck states twice and which is the single most
quizzable line in the lecture:

> When we say that the function $h$ is a linear parametric function, we essentially mean
> that it is only linear with respect to parameters $w$. Unless explicitly stated, we do
> not make any claims of its linearity with respect to the input $x$.

Its own example:

$$
h(x) = w_0 + w_1 x_1 + w_2 (x_2)^2 + w_3 (x_3)^3
$$

**is** a linear model. This is the same claim L3 made; the difference is that here it is
about to be cashed in, because polynomial regression is nothing but this observation
applied on purpose.

**Bias absorption** (slide 9) is carried over from L3 unchanged: write the $d$-dimensional
input as a $(d+1)$-dimensional vector $x = [1, x_1, \dots, x_d]$. The geometry the deck
attaches to the split:

- $[w_1, \dots, w_d]$ defines a **hyperplane** in $d$ dimensions.
- $w_0$, the **bias**, defines the intercept - how far the hyperplane sits from the origin
  on the $y$-axis.

## Training

*Slides 10-13.* Define an error metric measuring the discrepancy between prediction and
actual value on the training set. The reasonable choice is the square of the errors, and
it has a name:

$$
\operatorname{Loss}(D,w) = \operatorname{RSS}(D,w)
= \sum_{i=1}^{N}\big(y^i - h_w(x^i)\big)^2
= \sum_{i=1}^{N}\Big(y^i - w_0 - \sum_{j=1}^{d} w_j x^i_j\Big)^2 .
$$

**Residual Sum of Squares.** Note what is *not* there: no $\frac{1}{N}$, no
$\frac{1}{2}$ - it is a bare sum. The constant would not change $\hat w$, but it does
change every formula you copy from elsewhere, so use the deck's.

The subscript on $h_w$ is deliberate: the deck says it makes explicit that $h$ is a
parametric function with parameters $w$.

**Matrix form** (slide 12), which resolves the notation question
[L2](note.html?course=CSCI-UA-473&note=02-math-primer) flagged as open:

- $X$ is $N \times (d+1)$, **each row is one input example**, with the leading 1 column
  from bias absorption.
- $y$ is $N \times 1$, one output per example.

$$
\hat y = h_w(x) = w^{\mathsf T}x,
\qquad
\operatorname{RSS}(D,w) = (y - Xw)^{\mathsf T}(y - Xw).
$$

So: rows are examples, and the bias column is inside $X$. Pin that and use it everywhere.

**The closed form** (slide 13). At a minimum the gradient vanishes:

$$
\frac{d\operatorname{RSS}(D,w)}{dw} = -2X^{\mathsf T}(y - Xw) = 0
\qquad\Longrightarrow\qquad
\hat w = (X^{\mathsf T}X)^{-1}X^{\mathsf T}y,
$$

available "when one can invert the matrix $X^{\mathsf T}X$." The deck does not dwell on
when you cannot; [L2](note.html?course=CSCI-UA-473&note=02-math-primer)'s rank material
supplies it, and the ridge section below fixes it.

## Prediction

*Slide 14.* For a new example $x^0$, prepend the 1 and apply the learned weights:

$$
\hat y^{\,0} = [1\ \ x^0]\cdot \hat w = [1\ \ x^0]\,(X^{\mathsf T}X)^{-1}X^{\mathsf T}y,
$$

and the fitted values at the training pairs are

$$
\hat y = X\hat w = X(X^{\mathsf T}X)^{-1}X^{\mathsf T}y .
$$

The matrix sitting between $X$ and $y$ in that last expression is the one the next section
is about.

## Geometric interpretation

*Slide 15.* Take two-dimensional inputs, so $X \in \mathbb R^{N\times 2}$ with columns
$x_1, x_2$. Those two column vectors **span a subspace of $\mathbb R^N$**, and any
$\hat y = Xw = w_1x_1 + w_2x_2$ lies in it. So the model can only ever produce points in
the column space of $X$; least squares is the question of which one.

The optimality condition answers it. From the same derivative,

$$
X^{\mathsf T}(y - X\hat w) = 0
\qquad\Longleftrightarrow\qquad
X^{\mathsf T}(y - \hat y) = 0,
$$

i.e. the **residual is orthogonal to every column of $X$**. Hence:

> The resulting estimate $\hat y$ is the orthogonal projection of $y$ onto the subspace
> spanned by $X$.

This is the payoff L2 promised when it derived $\operatorname{proj}_a(x)$ from orthogonality
of the residual and said it would be back. The normal equations are that derivation read
line by line, one column at a time.

## Model interpretation

*Slides 16-17.* Accuracy is not the only question; which features are informative matters
too. The deck's machinery assumes the observations $y^i$ are **uncorrelated with constant
variance** $\sigma^2$, estimated from the training examples as

$$
\hat\sigma^2 = \frac{1}{N-d-1}\sum_{i=1}^{N}\big(y^i - \hat y^i\big)^2 .
$$

The $N-d-1$ rather than $N$ is the usual degrees-of-freedom correction: $d+1$ parameters
were fitted from the same data.

**Per-feature: the Z-score.**

$$
z_j = \frac{\hat w_j}{\hat\sigma \sqrt{v_j}},
\qquad v_j = \big[(X^{\mathsf T}X)^{-1}\big]_{jj},
$$

and informally, the smaller $|z_j|$, the less important feature $j$. Note that this is not
$\hat w_j$ on its own - a large coefficient on a feature whose estimate is unstable (large
$v_j$) scores low, which is exactly the correction that raw-coefficient reading misses.

**Per-group: the F-statistic.** To assess a group of coefficients simultaneously, compare a
bigger model with $d_1 + 1$ parameters against a **nested** smaller one with $d_0 + 1$:

$$
F = \frac{(\operatorname{RSS}_0 - \operatorname{RSS}_1)/(d_1 - d_0)}{\operatorname{RSS}_1/(N - d_1 - 1)} .
$$

It measures the change in residual per parameter added, scaled by the residual per
remaining degree of freedom. Nested is the operative word; the test says nothing about two
models that are not one inside the other.

## Basis expansion

*Slide 18.* Everything so far has been linear in $x$ as well as in $w$, and that second
restriction is unnecessary. Replace the raw inputs with fixed non-linear functions:

$$
h_w(x) = w_0 + \sum_{i=1}^{d} w_i\,\phi(x_i),
$$

where the $\phi$ are the **basis functions**. The deck's three families:

| Kind | Example |
|---|---|
| Transformations of inputs | $\log(x_1), \dots, \log(x_p)$ |
| Basis expansion | $x_{i+1} = x_1^2$, $x_{i+2} = x_1^3$ |
| Composition of variables | $x_{i+1} = x_1 \cdot x_2$ |

The last row is worth noticing - interaction terms arrive by the same door, and cost
nothing extra in the machinery.

## Polynomial regression

A special case of multiple regression where every input feature is a polynomial function of
one base feature. With $x = [x_1]$, model $y$ as an $n$-variable linear regression:

$$
y = w_0 + w_1\phi_1(x_1) + \dots + w_n\phi_n(x_1)
  = w_0 + w_1x_1 + w_2x_1^2 + \dots + w_nx_1^n .
$$

Non-linear in $x$, still linear in $w = [w_0, \dots, w_n]$, so estimating $\hat w$ follows
*the same process as before* - the same $(X^{\mathsf T}X)^{-1}X^{\mathsf T}y$, with $X$ now
the design matrix of powers.

The section closes on a figure fitting polynomial models of increasing degree to a fixed
set of points and reporting **RMSE**. The text layer of that slide is thin, so check the
recording for which degrees were shown and where the error turns around; the shape is the
one L4 already drew with its ten-point sine and $M = 9$.

## Subset selection

Linear models with many variables, fitted by least squares, have **two flaws**:

1. They tune well on the training snapshot but may not have low out-of-sample error. With
   many variables you will likely overfit: **low bias, high variance**.
2. A model with many variables is **less suited to interpretation**. Typically you want to
   know which handful of variables carry the predictive power.

Subset selection addresses both: identify which subset of features shows strong effects and
use only those. The framing the deck gives it - and this is the link back to L4 - is that
you are **limiting the capacity of your hypothesis space**.

The methods named (slide 22):

| Method | Note |
|---|---|
| **Best-subset selection** | efficient algorithms exist for $d$ as high as 30 or 40 |
| **Forward-stepwise** / **backward-stepwise** | |
| **Forward-stagewise regression** | |
| **Shrinkage** - ridge and lasso | listed here as a subset-selection method, then given its own section |

The $d \approx 30$-$40$ ceiling on best-subset is the whole motivation for the rest of the
list: exhaustive search over $2^d$ subsets stops being possible almost immediately, so the
stepwise methods are greedy approximations and shrinkage is the continuous relaxation.

## Shrinkage methods, a.k.a. regularization

Another way to reduce the capacity of the hypothesis space, aimed at better out-of-sample
error and at preventing overfitting on the training set. The deck's framing:

> They provide us with a lever to control how complex (or constrained) the hypothesis space
> we want to work with is.

Training is augmented so that minimizing the loss **shrinks or deletes the effect of
unimportant variables**. Two common choices.

### Ridge regression ($L_2$)

Imposes a penalty on the size of the coefficients:

$$
\operatorname{RSS}(D,w,\lambda) = (y - Xw)^{\mathsf T}(y - Xw) + \lambda\, w^{\mathsf T}w,
$$

and - the reason ridge is the one that gets taught first - the solution is still closed
form:

$$
\hat w_{\text{ridge}} = (X^{\mathsf T}X + \lambda I)^{-1}X^{\mathsf T}y .
$$

That $\lambda I$ is also the repair for the invertibility caveat back in the training
section: adding it makes the matrix invertible for any $\lambda > 0$ regardless of the rank
of $X$, so ridge gives a unique solution even when plain least squares has infinitely many.

The deck also gives the **effective degrees of freedom**,

$$
d(\lambda) = \sum_{i=1}^{d}\frac{d_i^2}{d_i^2 + \lambda},
$$

which is the $x$-axis of the coefficient-profile figure. At $\lambda = 0$ every term is 1
and $d(\lambda) = d$; as $\lambda$ grows each term decays and the effective parameter count
falls continuously. That is what "a lever on capacity" means quantitatively - the model
does not lose parameters, it loses *effective* ones.

### Lasso ($L_1$)

Similar, with a small difference. In constrained form:

$$
\hat w_{\text{lasso}} = \arg\min_{w}\sum_{i=1}^{N}\Big(y^i - w_0 - \sum_{j=1}^{d}x^i_j w_j\Big)^2
\quad\text{subject to}\quad \sum_{j=1}^{d}\lvert w_j\rvert \le t,
$$

and equivalently in penalized form with $+\lambda\sum_j \lvert w_j \rvert$. The deck labels
it directly: it **acts like a sparsity penalty**. The coefficient-profile figure is plotted
against the shrinkage factor

$$
s = \frac{t}{\sum_{j=1}^{d}\lvert w_j\rvert},
$$

and no closed form is given, because there is none.

### Ridge vs. lasso

The closing slide asks *when to choose which* and answers it geometrically. Both figures
show the same elliptical error contours around the unconstrained $\hat w$, with a shaded
**feasible region** for the parameters:

| | Feasible region in 2-D | Consequence |
|---|---|---|
| **Lasso** ($L_1$) | a **diamond**, with corners on the axes | the contour typically first touches a corner, where a coefficient is exactly zero - sparsity |
| **Ridge** ($L_2$) | a **circle**, no corners | the contour touches at a generic point; coefficients shrink but none is exactly zero |

Both panels below share one budget slider, one set of error contours, and one OLS
solution; only the shape of the shaded feasible set changes. The constraint is solved
exactly rather than sketched, so the sparsity claim is checkable: drag the budget down and
the lasso solution pins to $w_1 = 0$ over a whole range of $t$, while the ridge solution
slides around the circle and never lands on an axis.

```artifact src=demos/ridge-vs-lasso.jsx
```

The slide generalizes both into one penalty with an arbitrary exponent,

$$
\hat w = \arg\min_{w}\left[\sum_{i=1}^{N}\Big(y^i - w_0 - \sum_{j=1}^{d}x^i_j w_j\Big)^2
+ \lambda\sum_{j=1}^{d} w_j^{\,q}\right],
$$

with $q = 1$ and $q = 2$ the two cases taught. The corners are the whole story: sparsity is
a property of the *shape* of the constraint set, not of the size of the penalty.
